## Abstrak

Pada toko bangunan, pengelolaan penjualan, stok, dan pembelian masih banyak dilakukan secara manual atau melalui catatan terpisah. Kondisi ini kerap menimbulkan kesalahan pencatatan, keterlambatan rekap data, serta kesulitan memeriksa ketersediaan barang, terutama bagi usaha yang memiliki lebih dari satu cabang sehingga data antar lokasi belum tersatukan. Berdasarkan hal tersebut, penelitian ini bertujuan merancang aplikasi web penjualan, manajemen stok, dan pembelian yang dapat dimanfaatkan UMKM pada lingkup usaha toko bangunan agar ketiga proses tersebut dapat dikelola dalam satu sistem. Sistem dikembangkan untuk mendukung pencatatan transaksi penjualan, pembaruan stok, pencatatan barang masuk dari supplier, mutasi antar cabang, penanganan barang rusak dan retur, serta penyajian laporan penjualan dan pembelian. Metode penelitian yang digunakan adalah *System Development Life Cycle* (SDLC) dengan model Waterfall, meliputi analisis kebutuhan, perancangan sistem, implementasi, pengujian, hingga pemeliharaan. Perancangan sistem dilakukan dengan pendekatan *Unified Modeling Language* (UML), sedangkan basis data dikelola menggunakan MySQL. Antarmuka dibangun dengan HTML, CSS, dan JavaScript berpola Model–View–Presenter (MVP), dan data diolah melalui REST API berbasis PHP. Hasil penelitian berupa aplikasi berbasis web yang memungkinkan karyawan melakukan transaksi penjualan, input pembelian, serta retur ke supplier, sedangkan pemilik dapat mengelola akun, produk, cabang, supplier, memantau stok, mutasi barang, dan melihat laporan melalui antarmuka yang disediakan. Pengujian fungsional pada lingkungan lokal menunjukkan data transaksi tersimpan dengan benar dan jumlah stok berubah mengikuti setiap proses penjualan, pembelian, retur, maupun mutasi.

**Kata kunci:** aplikasi web, UMKM, toko bangunan, manajemen stok, penjualan, pembelian
